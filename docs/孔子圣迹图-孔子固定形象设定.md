# 《孔子圣迹图》孔子固定形象设定

## 核心目标

无论孔子处于讲学、出仕、周游、受困或晚年场景，观众都应当能够在第一眼认出孔子。识别方式参考传统宗教画、圣贤画中反复使用固定服色与圆光的做法，但保持中国古画的含蓄气质。

## 固定服饰

- 主袍：温润象牙白，不使用冷白或亮白。
- 衣缘：深靛蓝宽边，贯穿领口、袖缘和下摆。
- 腰带：暗赭红，低饱和度。
- 冠帽：深褐或黑色，随年龄和官职变化样式，但不改变主色。
- 鞋履：黑褐色履。
- 官职变化：只调整冠帽、佩绶、竹简等身份配件，不改变象牙白主袍与深靛蓝衣缘。

## 固定人物特征

- 成年孔子为高大、端正、沉静的男性形象。
- 面形略长，眉目温厚而有威仪。
- 中年以后留整齐的黑褐色长须；晚年可略带灰白，但脸型保持一致。
- 姿态克制，常用拱手、执简、抚琴、正坐等礼仪动作。
- 不画成帝王，不使用明黄色、龙纹或帝王冕旒。

## 圣人圆光

- 孔子脑后固定设置一圈淡金色圆光，作为跨场景识别标志。
- 圆光为薄而完整的圆环或极淡金色圆盘，直径略大于头部。
- 色彩低饱和、半透明，与旧绢底色自然融合。
- 不发射光芒，不使用火焰纹、佛像背光或西方宗教金色光束。
- 圆光不得遮挡面部、冠帽、题跋或关键人物。
- 画面中只有孔子拥有圆光，其他人物一律不加。

## 系列固定版式

- 画幅：16:9横构图。
- 风格：顾恺之及六朝人物画语言，高古游丝描、绢本淡设色、手卷式叙事。
- 左上角：粗篆朱印“孔子圣迹”。
- 题名：朱砂红竖排。
- 说明：淡墨小楷竖排，自右向左阅读。
- 左下角：系列编号“（36-N）”。
- 不添加现代字体、水印、边框或额外签名。

## 颜色参考

- 象牙白主袍：暖白、米白之间，避免与绢底完全融为一体。
- 深靛蓝衣缘：接近沉稳藏蓝，避免鲜蓝。
- 暗赭红腰带：接近旧朱砂、铁锈红。
- 淡金圆光：接近旧金粉，透明克制。

本设定自第20幅《丑次同车（二）》起执行；已完成的01—19幅待全套36幅完成后统一校色与补加圆光。
