## 2. 已确定的产品方向

- 画册馆收录“有趣、成套、有故事、值得完整翻阅”的中国古代图册；单幅中外名画不放在这里。
- “画册”和“中外名画”是两个馆：成套图册进 `/albums`，独立名画以后进 `/gallery`。
- 首册为《三十三剑客图》，符合画册馆的成套阅读方向。
- 以后画册增多时，馆藏页采用“少量精选画册展示 + 完整目录”，不把所有画册都塞进一个轮播。
- 全站页脚署名统一为“由 力清工作室 制作维护”。

## 3. 当前完成状态

### 路由

- `/albums`：画册馆馆藏页。
- `/albums/sanshisan-jianke-tu`：《三十三剑客图》目录、来源与整理。
- `/albums/sanshisan-jianke-tu/000` 至 `/034`：35 个册页；`000` 为封面，`001` 至 `033` 为33幅人物图，`034` 为全体群像结页。
- `/album-assets/[...path]`：画册图片入口。开发环境优先读取本地图片，其他环境跳转到图片 CDN。

### 馆藏页轮播

- 《三十三剑客图》精选第 `001`、`009`、`013`、`029`、`033` 图。
- 每 7 秒自动切换；鼠标停留、手指按住、页面离开屏幕或浏览器标签页不可见时暂停。
- 电脑可点左右箭头，手机可左右滑动。
- 点击当前场景进入对应的单图阅读页。
- 首页只显示册页右侧的故事场景，不显示左侧题字、正文残片；完整册页只在阅读页呈现。
- 当前图立即加载，并预加载下一图；不要在首页一次加载整册图片。

### 阅读页与放大层

- 电脑：键盘 `←` / `→` 前后翻页。
- 手机：1 倍时左右滑动翻页。
- 放大超过 1 倍后，拖动手势只平移画面，不触发翻页。
- 放大层保留“上一页 / 下一页”按钮；支持 1～4 倍缩放和双击缩放。
- 邮票大图查看器采用同一手势原则：“上一枚 / 下一枚”、键盘切换、手机滑动、放大后拖动。

### 单册目录

- 桌面端一排4个册页，《三十三剑客图》35个册页共9排。
- 手机端保持单列，较宽手机与小屏平板为两列，不用缩小字号硬塞四列。

## 4. 文件职责

- `data/albums/sanshisan-jianke-tu.json`：画册元数据、35 个册页、册页类型 `kind` 及 `featuredEntries` 精选图编号。未写 `kind` 的人物图由数据层统一视为 `plate`。
- `lib/albums.ts`：画册数据读取、册页类型补全、图片 URL 和单页查找。
- `app/albums/page.tsx`：馆藏页及画册介绍卡片。
- `components/AlbumPreviewCarousel.tsx`：同一本画册的精选场景轮播。
- `app/albums/[slug]/page.tsx`：单册目录、收录理由、来源与外部链接。
- `app/albums/[slug]/[number]/page.tsx`：单页阅读页。
- `components/AlbumViewer.tsx`：画册放大、缩放、拖动和前后翻页。
- `app/album-assets/[...path]/route.ts`：本地图片与 CDN 的统一入口。
- `components/StampGallery.tsx`：邮票大图查看与相同手势规则。
- `app/globals.css`：画册馆底色、书衣、旧纸、轮播淡入等样式。

- 手机轮播与画册大图在 1 倍时测试左右滑动；放大到 2 倍后确认横向拖动不会换页。
- 数据、路由或构建边界变化较大时，再运行 `npm run build`。

## 8. 多人共用工作区规则

- 该工作区可能同时存在多个 AI、会话或人工修改。开始和结束时都运行 `git status --short`。
- 不使用 `git reset --hard`、`git checkout --` 清除他人改动，不使用 `git add -A` 混入无关文件。
- 只精确暂存自己确认过的文件；发现重叠修改时先比较当前 diff，不根据 handoff 覆盖现状。
- 当前画册馆、邮票查看器和若干邮票数据存在未提交改动。接手人必须以当时的 `git status` 为准，不把本文列出的文件状态当成永久事实。
- 完成代码和验收后停在本地；只有站长明确要求“提交、push、上线”时才执行。

## 9. 下一步增加画册时

1. 先确认画册名称、原作、年代、来源、页数、图片版权与本站整理边界。
2. 建立独立的 `data/albums/<slug>.json`，使用稳定的小写 slug 和三位数页码；封面、正文图、结页分别使用 `cover`、`plate`、`end`。
3. 为馆藏页人工选 4～6 张场景差异明显的 `featuredEntries`，不要机械取前几页。
4. 保证首页轮播只显示故事场景；进入阅读页后才显示完整册页。
5. 图片进入独立图片仓库，主仓库只保留数据、代码和必要清单。
6. 完成类型检查、桌面与 375px 验收，再由站长决定是否提交和上线。
